## 🚀 Como Revisar um Volume

Se você vai revisar o texto de algum volume:

1. **Abra a comparação visual no seu navegador:**
   ```bash
   .\lnc comparar fate-apocrypha/1 --abrir
   ```
   *(No Linux/Mac, use `./lnc` em vez de `.\lnc`)*
   Isso abre uma visualização lado a lado: **original na esquerda, tradução na direita**. Linhas amarelas indicam trechos iguais ao original.

2. **Edite os arquivos de tradução:**
   Abra os arquivos em `obras/<obra>/vol-<n>/translation/translated-html/` no seu editor de texto preferido. Ajuste o texto mantendo as tags HTML (`<p>`, `<em>`, etc.).

3. **Valide automaticamente:**
   ```bash
   .\lnc validar fate-apocrypha/1
   ```
   Confere tags XML, encoding, acentuação perdida, falas com travessão e termos crus do glossário.

4. **Marque no checklist:**
   Abra `obras/<obra>/vol-<n>/REVISAO.md` e marque `[x]` nos arquivos que revisou.

👉 Leia o passo a passo completo em [`docs/GUIA_DO_REVISOR.md`](docs/GUIA_DO_REVISOR.md).

## 🛠️ Comandos Principais (`lnc`)

Tudo é gerenciado pelo script `lnc` (usa somente Python 3 padrão, sem necessidade de instalar dependências):

| Comando | Descrição |
|---|---|
| `.\lnc status` | Mostra a situação de todos os volumes e o progresso da revisão. |
| `.\lnc comparar <volume> --abrir` | Gera HTML com original x tradução lado a lado e abre no navegador. |
| `.\lnc validar <volume\|todos>` | Roda checagens automáticas de integridade, encoding e termos. |
| `.\lnc preparar <epub> <obra> <n>` | Prepara uma nova oficina a partir de um EPUB original. |
| `.\lnc sincronizar <volume>` | Copia as traduções revisadas de volta para o pacote do EPUB. |
| `.\lnc montar <volume>` | Recompila o EPUB a partir do pacote (`build/`). |
| `.\lnc publicar <volume>` | Valida + sincroniza + recompila + copia para `publicados/`. |

## ⚖️ Padrões Editoriais Type-Moon

1. **Diálogos com aspas duplas:** É estritamente proibido o uso de travessão (`—`) para marcar falas. Diálogos ficam entre `" "`.
2. **Classes de Servant não são traduzidas:** `Saber`, `Archer`, `Lancer`, `Rider`, `Caster`, `Assassin`, `Berserker`, `Ruler`, etc.
3. **Glossário oficial prevalece:** Antes de alterar termos de magia, facções, locais ou conceitos, consulte `padroes/GLOSSARIO_TYPEMOON_OPERACIONAL.json`.
